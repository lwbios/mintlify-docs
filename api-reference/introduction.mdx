## Gerenciamento de chaves de API e autenticação

<Steps>
  <Step title="Chaves de API de acesso">
    Acesse o [Dashboard da Valora](https://dash.valora.cash) e faça login.
  </Step>
  <Step title="API aberta e webhooks">
    Acesse a seção API e Webhooks na barra lateral:

    1. Adicione o URL do seu Webhook — a Valora envia atualizações de status aqui.
    2. Copie sua chave de API — mantenha-a apenas no servidor, nunca a exponha no código do frontend.
  </Step>
  <Step title="Guarde sua chave em segurança.">
    Copie a chave gerada imediatamente e certifique-se de armazená-la em local seguro.
  </Step>
  <Step title="Autentique suas solicitações de API">
    Utilize suas chaves de API para autenticar todas as solicitações. Aplique o seguinte formato de autorização:

    ```shellscript
    'x-api-key: YOUR_API_KEY'
    ```
  </Step>
</Steps>

## Limites de taxa

Nossa API utiliza um sistema de limitação de taxa de requisições com janela dupla e proteção contra picos de tráfego. Os limites são aplicados com base no seu método de autenticação e plano de negócios.

### Limites padrões

| **Endpoint** | Limite | **Janela** |
| --- | --- | --- |
| `GET` | 30 req | 60s |
| `POST` | 30 req | 60s |
