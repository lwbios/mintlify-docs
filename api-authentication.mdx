---
title: "Autenticação de API"
---

Autentique solicitações da Valora com chaves de API com escopo definido. Envie sua chave secreta via cabeçalho HTTP. Chaves ausentes ou inválidas retornam um erro 401.

## Encontrando sua chave de API

Uma chave de API é gerada automaticamente para cada aplicativo que você cria. Para encontrar sua chave:

<Steps>
  <Step title="Faça login no Dashboard">
    Acesse o [Dashboard da Valora](https://dash.valora.cash) e faça login.
  </Step>
  <Step title="API aberta e webhooks">
    Acesse a seção API e Webhooks na barra lateral esquerda.
  </Step>
  <Step title="Copie suas chaves">
    Sua chave de API e chave secreta do webhook serão exibidas aqui. Copie-as conforme necessário.
  </Step>
</Steps>

## Fazendo solicitações autenticadas

Para autenticar uma solicitação de API, inclua sua chave secreta de API no `x-api-key`cabeçalho HTTP.

Segue um exemplo de uma requisição autenticada para o `pixQrCode` endpoint:

```shellscript
curl --request POST \
     --url https://prod.api.valora.cash/v1/pixQrCode/ \
     --header 'accept: application/json' \
     --header 'content-type: application/json' \
     --header 'x-api-key: YOUR_API_KEY' \
     --data '
{
  "amount": "1"
}
'
```

## Tratamento de erros

Se a sua chave de API estiver ausente ou for inválida, a API retornará a `401 Unauthorized`seguinte resposta:

```json5
{
	"error": "Header x-api-key ausente"
}
```

| Status | Código | **Causa** |
| --- | --- | --- |
| `401` | `HEADER "X-API-TOKEN" AUSENTE` | Header não enviado |
| `403` | `TOKEN INVÁLIDO, INATIVO OU EXPIRADO` | Token errado ou desativado |
| `403` | `REQUISIÇÃO BLOQUEADA` | Bot ou padrão suspeito (SQLi, XSS, path traversal) detectado pelo Escudo |
| `429` | `LIMITE DE REQUISIÇÕES EXCEDIDO. AGUARDE 60S` | Rate limit atingido |
| `500` | `ERRO INTERNO DO SERVIDOR` | Falha interna |
